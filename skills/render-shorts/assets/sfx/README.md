# Bundled SFX set

Five short, license-free, fully synthesized sounds used by the Remotion
Assembly `sfx` prop (see `skills/render-shorts/remotion/src/schema.ts`). No downloads, no
third-party samples -- everything is generated by ffmpeg filters, so the set
is reproducible and unencumbered.

| File         | Length | Character                                            |
| ------------ | ------ | ---------------------------------------------------- |
| `whoosh.wav` | 350ms  | pink noise, band-pass center swept 1800→380 Hz       |
| `pop.wav`    | 120ms  | sine burst swept 400→80 Hz, fast decay               |
| `tick.wav`   | 60ms   | 2 kHz click, very fast decay                         |
| `ding.wav`   | 450ms  | E6+E7 chime (1318.51 + 2637.02 Hz), gentle decay     |
| `type.wav`   | 50ms   | band-limited (500–2200 Hz) noise click, softer than tick |

Format: 48 kHz mono, 16-bit PCM wav, each peak-normalized to ~−20 dBFS
(headroom on purpose: the Assembly plays cues at −16 dB gain by default and
clamps at −6 dB, so SFX sit under the voiceover).

## Regenerating

```bash
bash skills/render-shorts/assets/sfx/generate.sh          # rewrites skills/render-shorts/assets/sfx/*.wav
cp skills/render-shorts/assets/sfx/*.wav skills/render-shorts/remotion/public/sfx/   # keep the render copy in sync
```

`generate.sh` documents each synthesis command inline. The underlying
commands (all one ffmpeg invocation per sound, then a `volumedetect` →
`volume=<delta>dB` peak-normalize pass to −20 dBFS):

```bash
# whoosh -- noise sweep down (asendcmd re-tunes the bandpass every 50ms)
ffmpeg -f lavfi -i "anoisesrc=r=48000:colour=pink:amplitude=0.8:seed=20260704:duration=0.35" \
  -af "asendcmd=c='0.05 bandpass@s f 1450; 0.10 bandpass@s f 1150; 0.15 bandpass@s f 900; \
0.20 bandpass@s f 700; 0.25 bandpass@s f 520; 0.30 bandpass@s f 380',\
bandpass@s=f=1800:width_type=o:w=1.4,afade=t=in:d=0.04:curve=tri,afade=t=out:st=0.18:d=0.17:curve=tri" \
  -ar 48000 -ac 1 -c:a pcm_s16le whoosh.wav

# pop -- exponential 400→80 Hz sweep: phase K = f0*T/ln(f1/f0) = -29.8241
ffmpeg -f lavfi -i "aevalsrc='sin(2*PI*(-29.8241)*(exp(log(0.2)*t/0.12)-1))*exp(-t*28)':s=48000:d=0.12" \
  -af "afade=t=out:st=0.10:d=0.02" -ar 48000 -ac 1 -c:a pcm_s16le pop.wav

# tick -- 2 kHz, exp(-90t) decay
ffmpeg -f lavfi -i "aevalsrc='sin(2*PI*2000*t)*exp(-t*90)':s=48000:d=0.06" \
  -af "afade=t=out:st=0.05:d=0.01" -ar 48000 -ac 1 -c:a pcm_s16le tick.wav

# ding -- E6 + E7 partials, exp(-7t) decay
ffmpeg -f lavfi -i "aevalsrc='(sin(2*PI*1318.51*t)+0.5*sin(2*PI*2637.02*t))*exp(-t*7)':s=48000:d=0.45" \
  -af "afade=t=in:d=0.004:curve=tri,afade=t=out:st=0.40:d=0.05" -ar 48000 -ac 1 -c:a pcm_s16le ding.wav

# type -- deterministic noise (random(0) state starts at 0), band-limited
ffmpeg -f lavfi -i "aevalsrc='(2*random(0)-1)*exp(-t*130)':s=48000:d=0.05" \
  -af "lowpass=f=2200,highpass=f=500,afade=t=out:st=0.04:d=0.01" -ar 48000 -ac 1 -c:a pcm_s16le type.wav
```

Determinism verified on ffmpeg 8.1.1 (macOS arm64): re-running produces
byte-identical wavs (`anoisesrc` seeded; `aevalsrc` `random(0)` starts from
expression state 0). A different ffmpeg build may produce slightly different
bytes but the same sound.

## Usage in the Assembly

```jsonc
"sfx": [
  { "atMs": 6370, "name": "whoosh" },            // default gain -16 dB
  { "atMs": 12000, "name": "ding", "gainDb": -12 } // clamped at -6 dB max
]
```

Names resolve to `staticFile("sfx/<name>.wav")`, i.e. files must exist in
`skills/render-shorts/remotion/public/sfx/`. Mixing rules (max ~6 cues, where to place
them) live in `skills/render-shorts/rules/remotion-editor.md`.
