# Music tracks (manual step -- human only)

Drop license-safe background tracks here, named by mood so the editor stage
can pick by the storyboard's `music_mood`:

```
curious-tech-01.mp3      # light synth pulse, curious, 90-110bpm
steady-build-01.mp3      # rising, purposeful
warm-optimist-01.mp3     # warm, friendly close
```

Source: YouTube Audio Library (studio.youtube.com → Audio Library) -- filter
"Attribution not required", download 2-3 per mood. Do NOT commit tracks whose
license requires attribution unless the attribution line is added to the
video description template.

Until this folder has tracks, the pipeline renders Shorts without music
(by design -- silence beats a wrong vibe, per the editor appendix).
