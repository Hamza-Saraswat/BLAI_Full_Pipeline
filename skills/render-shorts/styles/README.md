# Style packs -- the anti-sameness system

One brand, seven looks. The storyboard picks ONE pack per video; scene workers
load `skills/render-shorts/styles/<pack>.md` instead of guessing aesthetics.

The seven cover seven distinct visual *processes* -- kinetic type (signal),
CLI text (terminal), hand drawing (sketch), technical drafting (blueprint),
dimensional 2.5D diagram (axon), print (halftone), physical hardware
(silicon) -- no two packs share a background hue family or a motion grammar.

## Shared brand anchors (LOCKED -- identical in every pack)

- **Amber accent `#FFB347`** -- the highlight color everywhere, every pack.
- **Dark-family background** (each pack's own dark; never light -- brand
  recognition in the feed + the safe-zone linter's bright-pixel detection
  depends on dark margins).
- **Caption style + geometry** -- unchanged across packs (owned by Assembly).
- **Safe zones + caption band** -- geometry never varies by pack.
- **Wordmark settle** in the loop-anchor final frame.
- **Narration voice** -- the ElevenLabs Professional Voice Clone (`ELEVEN_VOICE_ID`,
  generated by `skills/elevenlabs-narration`); one voice per video, never
  changed mid-video. Brand voice rules (`brand-vault/`) are locked.
- **Success `#7BD88F` / error `#FF6B6B`** semantic colors.

## Selection rules (applied at storyboard time; `scripts/style_rotation.py`)

1. Pick by topic fit (table in each pack file; summary: terminal → CLI/
   tooling/setup topics; sketch → intuition/analogy-heavy concepts;
   blueprint → architecture/"how it works" internals; axon → system
   topology/data-flow stories (what happens inside the box); halftone →
   hot takes, benchmark face-offs, myth-busting; silicon → hardware
   anatomy (GPU/VRAM/bandwidth/quantization); signal → default,
   benchmarks, comparisons, news).
2. **Never the same pack twice in a row** -- `style_rotation.py --pick` checks
   `history.json`; `--record` appends on storyboard approval.
3. One pack per video. No mixing. A named series locks its pack.
4. Record the pick in the storyboard's `style_pack` field.

## Anti-sameness beyond packs

Every scene carries a `layout_archetype` (centered-stack | split-compare |
timeline | grid | giant-number | diagram-flow); adjacent scenes may not
repeat an archetype. Scene rhythm: vary durations (don't make every scene
~8s); stillness is contrast, use it after motion bursts.
