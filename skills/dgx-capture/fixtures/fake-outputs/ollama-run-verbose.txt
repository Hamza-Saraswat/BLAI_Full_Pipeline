A KV cache stores the key and value vectors the model already computed for earlier tokens, so it does not redo that work for every new word. Without it, each generated token would re-process the whole conversation, and generation would slow down as the text grows. The cost is memory: the cache grows with context length, which is why a 32k window needs more room than an 8k one.
