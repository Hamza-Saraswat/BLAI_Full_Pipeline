# Value Framework

A piece that tries to deliver every kind of value delivers none. Lock two before writing.

## Value Types

### TEACHES
The viewer understands something they did not before, well enough to explain it to a friend in one sentence.

### EQUIPS
The viewer can do something tonight: a command, a flag, a decision rule, a checklist.

### REFRAMES
The viewer sees a familiar thing differently, and the new frame changes a decision ("it's not the GPU, it's the doorway").

### PROVES
The viewer sees a real measurement from our hardware that settles a claim (tokens per second, memory, cost). This type is only available when the brief or a capture carries the number.

## How to Use

At the ideas stage, tag each candidate with the value types it naturally delivers. The chosen candidate's two locked types are written into the hub note and checked in the script audit: a script that does not deliver its locked types is revised, not saved.
