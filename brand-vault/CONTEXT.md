# Brand Vault

Identity, voice and content framework for Build Local AI. Stages load specific sections as their Inputs tables direct; nothing here is per-run.

| File | Key Sections | Load When |
|------|-------------|-----------|
| `voice-rules.md` | "Hard Constraints", "Sentence Rules", "Pacing", "Person by Format", "What the Voice Is NOT" | Writing any narration, on-screen text, title or description |
| `voice-rules.md` | "Strategic Rationale" | Understanding why the voice is what it is (rarely needed) |
| `identity.md` | "One-Sentence Brand", "Audience" | Knowing who is being addressed |
| `identity.md` | "Channel Facts" | A script or idea needs the hardware, the lanes, or the measured lessons |
| `identity.md` | "Positioning", "Content Mission" | Judging whether an idea or script serves the channel |
| `content-pillars.md` | The one pillar or series the run falls under | Ideation and scripting; load only the relevant section |
| `value-framework.md` | Full file | Locking value types at the ideas or outline stage; auditing delivery |
