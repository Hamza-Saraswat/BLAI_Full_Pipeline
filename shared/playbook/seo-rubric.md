# SEO and Packaging Rubric (0-100; require >= 80)

The package stage scores its own output with this rubric and revises until it passes. The score is written to the hub note (`seo_score`).

| Check | Points | Pass condition |
|-------|--------|----------------|
| Title keyword and length | 20 | primary keyword within the first 40 characters; <= 40 visible chars; accurate; <= 1 ALL-CAPS word; <= 1 emoji |
| Title type and complement | 10 | the chosen title is tagged searchable or intriguing and matches the target surface; title and thumbnail/hook text do not repeat each other |
| Description | 20 | keyword + plain-English promise in the first 150 characters; unique text; first line names the channel or the closest related video; <= 5,000 bytes |
| Hashtags | 5 | 2-3, relevant, product names first, no spaces |
| Tags list | 5 | <= 500 chars, primary keyword, 2-3 variants, 8-15 total, nothing irrelevant (kept for a future direct uploader) |
| Frame 1 | 15 | hook legible at frame 1 inside the safe area |
| Shorts physics | 10 | vertical, <= 180 s, hook in the first 2 s |
| Compliance | 15 | `containsSyntheticMedia` correct; made-for-kids false; `original_insight` written; no AI persona as a human expert on YMYL topics |

Scoring: each row is all-or-nothing except Description and Title (half credit when one sub-condition fails). Below 80: revise the failing rows and re-score.
