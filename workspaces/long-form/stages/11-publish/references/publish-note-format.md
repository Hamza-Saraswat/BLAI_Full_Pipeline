# Publish and Published Note Formats (long-form)

Same as the Shorts formats with three extra frontmatter fields in the publish note: `thumbnail_url`, `chapters_source` (`chapters.json`), and `series`. The published note carries `series` and `thumbnail_pick` and links the hub note, the package and the spec.

```
---
slug: [slug]
workspace: long-form
series: benchmarks
title: ...
published_slot: 2026-08-26T09:00:00-05:00
youtube_url: ""
blotato_post_id: ...
thumbnail_pick: 1
views_7d: 0
---
```
