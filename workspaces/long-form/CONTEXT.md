# BLAI Long-form Workspace

Take a local-AI topic or one of the creator's own DGX Spark projects to a scheduled 8-20 minute YouTube episode, three a week.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Sweep sources and input notes | `stages/01-radar/CONTEXT.md` | Digest with the creator's input notes as the priority lane |
| Pick the episode | `stages/02-ideas/CONTEXT.md` | Candidates, keyword research, series rotation, one pick, FYI card |
| Research + experiment plan | `stages/03-research/CONTEXT.md` | Deep brief and, when the episode touches the Spark, a guarded command plan |
| Outline | `stages/04-outline/CONTEXT.md` | Angle, two value types, hook, payoff, chapters, visual philosophy |
| Script | `stages/05-script/CONTEXT.md` | Full script with visual intent, plus narration.txt |
| Spec | `stages/06-spec/CONTEXT.md` | Scene list from the scene library, thumbnail concepts |
| Package | `stages/07-package/CONTEXT.md` | Titles, description with chapters, manifest |
| Capture | `stages/08-capture/CONTEXT.md` | Run the experiment on the Spark; reconcile numbers (Spark) |
| Voice | `stages/09-voice/CONTEXT.md` | Cloned-voice narration, QA, captions (Spark) |
| Render | `stages/10-render/CONTEXT.md` | Remotion episode, thumbnails, linters, gate card (Spark) |
| Publish | `stages/11-publish/CONTEXT.md` | Blotato upload with thumbnail and chapters (Spark) |
