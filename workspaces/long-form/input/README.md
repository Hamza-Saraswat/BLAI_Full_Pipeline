# Long-form input

Copy a note here from `Second Brain/Local Work/` when a project is ready to become an episode. Scrub anything private first: this folder is public. Good notes carry the commands you ran, the numbers you saw, what broke, and what you would tell a friend. Stage 01 treats every note here as the priority lane and stage 03 uses it as a primary source. Delete the note once the episode is published (the brief keeps the facts).
