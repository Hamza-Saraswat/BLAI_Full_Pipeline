GLOSSARY: Open WebUI | A self-hosted, offline-capable web platform for chatting with local and cloud models, run from Docker, pip or a desktop app.
GLOSSARY: Ollama | A local model runner that Open WebUI connects to, including a Docker image that bundles both together.
GLOSSARY: Folder workspace (0.13.5) | A sidebar folder that gets one computer and one project directory, where terminal, browser and chat tabs stay open together.
GLOSSARY: Open Terminal | Open WebUI's self-hosted sandboxed computer environment where a model can run commands, edit files, and use a browser and a desktop.
GLOSSARY: AGENTS.md / CLAUDE.md | Per-project instruction files that every new chat in a 0.13.5 project folder reads.
GLOSSARY: Agent Client Protocol (ACP) | The protocol Open WebUI uses to plug external coding agents such as Claude Code or Cursor in as selectable models.
