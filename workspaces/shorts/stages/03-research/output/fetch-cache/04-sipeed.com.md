### 256 TOPS beats "1,000 TOPS" in prefill?256 TOPS 为什么能赢"1000 TOPS"？

1,000 is sparse FP4, which real models can't use. Dense is 500 on paper, and on real models Spark puts only a small slice of it to work. MaixStation turns far more of its 256 into actual speed.1000 是稀疏 FP4 算力，真实模型用不上。稠密算力纸面也只有 500，跑真实模型时 Spark 只用上其中一小部分。MaixStation 能把 256 中大得多的比例变成实际速度。

### Same 273 GB/s. Why is decode faster?同样 273 GB/s，为什么解码更快？

Bandwidth sets the ceiling. Architecture decides how close you get. Every token reads the whole model once, and MaixStation keeps more of those 273 GB/s busy.带宽决定上限，架构决定离上限有多近。每生成一个 token 都要把模型读一遍，MaixStation 把这 273 GB/s 用得更满。

tok/s ≈ effective bandwidth ÷ model size

### I've seen Spark do 50+ tok/s on 27B.我见过 Spark 跑 27B 有几十 tok/s？

Those runs use MTP or speculative decoding. This chart turns MTP off on both sides for a like‑for‑like baseline. Turn it on, and MaixStation gets a similar speed‑up.那些数字开了 MTP 或投机解码。本图两边都关闭 MTP，用标准速率对比。开启 MTP 后，MaixStation 同样获得相近的加速比。

FAQ

When does it launch?什么时候上线？

Kickstarter, end of 2026. Reservation holders get the date first and 24 hours of priority on the Super Early Bird tier.Kickstarter，2026 年底。预缴意向金的用户第一时间收到日期，并享有 Super Early Bird 档位 24 小时优先。

What chip is inside?什么芯片？

AXERA AX8860P. 256 TOPS FP4, 256‑bit LPDDR5X‑8533, 273 GB/s. On a 78×78 mm Maix‑V module with an LPCAMM2 connector, shared by MaixStation, MaixStation Pro and MaixBlade.爱芯元智 AX8860P。256 TOPS FP4，256‑bit LPDDR5X‑8533，273 GB/s。位于 78×78 mm 的 Maix‑V 核心板，LPCAMM2 接口，MaixStation、MaixStation Pro 和 MaixBlade 共用。

Are vLLM and SGLang supported natively?原生支持 vLLM 和 SGLang 吗？

Yes. SGLang and vLLM run through a custom hardware‑acceleration backend whose kernels are written in AXDSL.支持。SGLang 和 vLLM 通过定制的硬件加速后端运行，算子用 AXDSL 编写。

Can I run my own Hugging Face models?能跑自己的 Hugging Face 模型吗？

Yes, directly. The stack is built on SGLang, so there is no separate conversion step. For a new architecture, you can write kernels in AXDSL. We'll open‑source the AXDSL kernels for every supported model along with the kernel development tooling, and a code agent can help port new models automatically.可以，直接跑。软件栈基于 SGLang，不需要单独的转换步骤。遇到新架构，可以用 AXDSL 自己写算子。我们会开源所有已支持模型的 AXDSL 算子和算子开发工具，代码 agent 也能帮你自动移植新模型。

Which OS and Linux kernel does it ship with?预装什么系统和 Linux 内核？

Debian 13 with Linux 6.18. We're working on open‑sourcing the AX8860 SDK and on a plan to upstream the code.Debian 13，Linux 6.18。我们正在推进 AX8860 SDK 开源，并计划把代码合入上游。

In PCIe card mode, which host OSes are supported? Windows?PCIe 加速卡模式支持哪些主机系统？Windows 呢？

Linux hosts come first, since LLM inference runs mainly on Linux. We'll add Windows support based on customer demand.优先支持 Linux 主机，大模型推理主要跑在 Linux 上。Windows 支持会根据用户需求推进。

Why no 64GB?为什么没有 64GB 版本？

No flagship open model lands there. 32GB runs the best dense 27B; 128GB runs the best 125B MoE. 64GB would run neither better. Enterprise customers who need it can order a custom build.没有与之匹配的高性能模型。32GB 跑最好的稠密 27B，128GB 跑最好的 125B MoE，64GB 两边都不占。有企业需求可以定制。
