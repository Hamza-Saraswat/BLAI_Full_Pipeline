GLOSSARY: dense model | A model where every parameter is used on every token (no expert routing), so "active parameters" equals total parameters.
GLOSSARY: reasoning_effort | A chat-template parameter (xhigh/medium/low) that injects instructions controlling how long Qwen3.8's thinking trace runs before the answer.
GLOSSARY: enable_thinking | The per-request switch (true/false) that turns the <think>...</think> preamble off entirely for direct instruct-mode answers.
GLOSSARY: preserve_thinking | Qwen3.8 default that keeps thinking blocks from prior turns in context for continuity, at the cost of extra tokens and KV cache.
GLOSSARY: Gated DeltaNet | The linear-attention layer type stacked 3:1 against full gated attention in Qwen3.8's hybrid layout, keeping long-context memory cheap.
GLOSSARY: YaRN | A RoPE-scaling technique that stretches Qwen3.8-27B's native 262,144-token context to 1,000,000 tokens.
GLOSSARY: KV cache | The per-token memory the inference engine keeps for attention, added on top of model weights and scaling with context length and concurrency.
GLOSSARY: MTP (Multi-Token Prediction) | Qwen3.8's trained capability to predict multiple future tokens, usable for speculative decoding at ~1-2GB extra memory.
