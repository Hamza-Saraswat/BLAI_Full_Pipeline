3. **Nari Qwen3-TTS / Qwen3-ASR (60)** -- An open TTS+ASR pair claiming top Coval benchmark spots means voice-in and voice-out for a local agent no longer need a cloud API; measure latency on your own GPU before trusting the benchmark claim.
4. **llama.cpp b10985 (56)** -- Third llama.cpp release in about 4 hours; check the release notes before debugging a fresh crash, because your issue may already be fixed upstream.
5. **llama.cpp b10984 (55)** -- Same cadence; the CUDA-tagged notes are the ones to skim if you run NVidia cards.
6. **llama.cpp b10983 (55)** -- Same cadence; pin a known-good tag if you script updates, three-a-day releases will otherwise churn your queue.
7. **Sunk Cost (50)** -- The tool computes when a local rig pays for itself against API list prices; the number that decides it is your own monthly token spend, which most people have never measured.
8. **Ollama v0.34.1-rc2 (47)** -- A release candidate of a patch release; hold for the final unless you specifically need the ChatGPT-import or MLX fixes it carries.
9. **Pelican-bicycle alternatives (47)** -- No local angle: static-site generator tooling; scored down.
10. **Otis (41)** -- A minimal agent that drives llama.cpp out of the box, so the floor for a first local agent drops from a framework install to one binary; the trade to measure is capability lost versus OpenHands-class setups.
11. **Qwen3.8-Flash-Next GSQ-RCO GGUF (35)** -- Non-uniform quantization puts a Flash-Next build on 2 RTX 3090s (48 GB), hardware far below a DGX Spark; relates to but does not contradict the published 2026-09-02 Short (DGX Spark, 43 tok/s) -- different hardware, different quant. The number to verify is tok/s at that quant on 48 GB.
12. **Tuning a local coding agent (34)** -- Oh My Pi plus Qwen3.8-27B tuned on two used RTX 3090s is a working local coding agent on roughly 700 dollars of GPUs; the measurement that matters is tokens-to-green versus your API bill.
13. **4x DGX Sparks (32)** -- A team that bought four Sparks published the why: rack, power and multi-node math; the figures to lift are watts idle/loaded and what 4x128 GB unified actually unlocks versus one box.
14. **Warp, DeepSeek v4.1 Flash in 5 GB (30)** -- 3.77 tok/s from 5 GB of RAM proves the 4-bit build pages from disk: fine for batch jobs, dead for chat; the threshold to measure is RAM where tok/s becomes interactive.
15. **DeepSeek outage (30)** -- API, app and web down while local GGUF builds kept answering; a one-line pitch for local that needs no extra evidence.
