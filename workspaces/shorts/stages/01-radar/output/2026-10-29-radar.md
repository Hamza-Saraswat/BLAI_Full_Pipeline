## So-What (top 15)

Per references/so-what-rules.md: what changes for someone running AI on their own hardware.

1. **86 Qwenputer (Qwen3.5-4B)** -- a 4B model with a deterministic RISC-V CPU compiled into its weights, using Gated DeltaNet state as RAM; it runs arithmetic, C and MicroPython inside forward passes with no tools. Weights are on HF, so anyone can run it locally today; it is also a worked example of what "the model is the computer" could mean for local inference.
2. **73 open-webui v0.12.5** -- admins get a Sessions tab listing each chat with tokens, errors and time span; if you self-host Open WebUI you can finally see which local models burn tokens and fail, per chat.
3. **64 transformers v5.21.1** -- fixes the rope_scaling bug that broke remote code loading in vLLM; if vLLM serving broke on a custom architecture after the last upgrade, this patch is the reason to upgrade transformers first.
4. **63 ollama v0.40.13** -- adds Liquid AI LFM3 (plus lfm3-audio text-to-speech and lfm3-omni) on Linux and Windows; one `ollama pull lfm3` is now the shortest path to a local audio-capable model.
5. **59 unsloth v0.1.912-beta** -- faster first launch and Linux tool-call fixes; fewer wasted minutes before a fine-tune starts on a single GPU.
6-8. **56/55/55 llama.cpp b11979-b11981** -- three releases in one day: SYCL gets a DPAS flash-attention kernel for quantized KV cache (decode with 1-31 query tokens), vectorized Q4_0/K-quants/IQ3/MXFP4 dequant stores, and Hexagon doubles DDR bandwidth utilization in transposed CONCAT. Owners of Intel/Qualcomm hardware measure decode speed; everyone else can skip.
9. **54 MicroZig no-LLM policy** -- an embedded project banning AI contributions; no local angle, but a signal of where open-source maintainers draw the line on machine-generated code.
10. **47 TensorRT-LLM v1.4.0rc2** -- release candidate for local NVIDIA serving; note the Python wheel is 1.4.0rc2.post1 while containers say 1.4.0rc2, a version trap for anyone scripting installs.
11. **30 DeepSeek-v4.1-Flash KV cache compression paper** -- the paper behind the model many already run from GGUFs; read it to know how far KV compression can be pushed before you measure it yourself.
12. **29 Claude Code adds your email to the prompt** -- an agent leaking your identity to whatever it browses is the argument for running agents against local models where you control the logs; no product number, this is a policy consequence.
13. **29 Manchurian Candidate in Qwen weights** -- a claim of hidden behavior in open weights plus a same-day rebuttal (item 22, XDA: Qwen invents URLs with real key IDs); for local runners the lesson is to pin and hash the checkpoints you serve.
14. **27 Harness Corp** -- a full incremental game driven by Qwen3-0.6B in the browser over WebGPU (~358 MB download); proof a real local model now ships as a web page, no install.
15. **26 MealWords** -- a cloud ChatGPT wrapper for travel cards; no local angle.

Contradictions with published titles: none flagged; no published Short claims a position these items overturn.
