# So-What Rules

Each of the top 15 radar items gets one line answering: what changes for someone running AI on their own hardware?

- Name the product and the consequence in the same sentence: "Ollama 0.33 adds FP8 loading, so a 32B model now fits a 24 GB card."
- Prefer a number over an adjective. If the item has no number, say what would need measuring.
- If the item only matters to cloud users or to enterprises without a local angle, say "no local angle" and score it down.
- If the item contradicts something the channel said before, write "contradicts: [published title]" so the ideas stage can plan a correction.
- Never speculate beyond the source. The so-what is a reading of the item, not a prediction.
