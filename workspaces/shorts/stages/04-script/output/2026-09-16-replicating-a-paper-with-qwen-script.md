# Jev's speed isn't in the weights

## Decisions

- Two structures tried: how-to-three-moves (draft A) and myth-bust (draft B). B won 24 to 12 on the judge rubric: it pays the contradiction off inside four seconds and lands on a repeatable line; A held its first concrete number past twenty seconds. No grafts.
- Hook: candidate 1, named-contradiction ("Jev's speed isn't in the weights. Your Qwen already has it."). Rotation barred number-shock and situation (last two ledger entries); tonight was kept for draft A only.
- Number spend: 312-vs-1 passes, 270 ms, and the 270 ms ghost-match against Jev's vendor 70-to-500 ms row (substring artifact of "two hundred seventy"). The 1,900 ms baseline is spoken but kept off screen in both drafts so the cap holds; reason recorded here rather than cutting a spoken number the listener needs.
- Validator on the winner: 0 blockers, 0 advisories. Eval gates: all pass, no soft advisories remaining. Lexicon edits: say-entries added for JSON ("jason"), LM and LM Studio; self-test 138/138 after the edit.
- Judges note: the judge scored A's row 4 as 0 partly for the on-screen 1,900 ms that had already been fixed pre-judging; corrected score would be A 15, B still wins 24.
