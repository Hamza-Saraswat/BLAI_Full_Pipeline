## Description

```
Unsloth LAN access without a tunnel: reach your own box from your own network in three settings and one password. Then read what the switch actually opens.

Unsloth binds to loopback by default. A wildcard bind, from Settings or with the host flag, makes it answer every address the machine has. Unsloth stops and forces you to replace the generated admin password first.

The part the release notes do not lead with: Unsloth's own docs warn that server-side tools run as your user, and anyone reaching the server with your API key can run code on that machine. Pass the disable-tools flag unless you meant to hand that out.

More local AI on the channel: https://www.youtube.com/@BuildLocalAI
```
