## Description
Ollaya runs open decision models, small nets that answer typed questions with calibrated probabilities instead of writing text, on your own GPU through an Ollama-style CLI. This Short walks the honest version: the 10 ms figure is Ollaya's own RTX 4090 benchmark, the base laya checkpoint sits near chance until you use the fine-tuned one, and every probability threshold needs calibrating on your own data. If you run Ollama today, this is the same one-command move for decisions.
