## Description
Offline AI on a USB stick: llamafile and Kiwix pack a local LLM plus all of offline Wikipedia onto one drive, no internet needed. You download two files, copy them to a stick, and any computer answers with the network off.

We open the kit live: a 2.02 GB llamafile (a model and its engine in one program, no install) and a Wikipedia ZIM (Kiwix's offline archive format). The catch, honestly: Windows blocks single executables above 4 GB, and a small model paraphrases, so it shows the passage it read.
