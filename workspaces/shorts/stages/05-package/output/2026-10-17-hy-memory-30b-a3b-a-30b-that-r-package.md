## Description
Hy-Memory-30B-A3B is Tencent's memory writer: the 30B model that edged Claude Opus 5 at remembering and runs locally from an 18 GB file.

It is not a chat model. It is the specialist that decides what Mem0 and MemOS store, update and overwrite for your local assistant, so your chat model stays whatever it already is. This Short covers what a memory writer is, what the benchmark actually says (Tencent's own tests, 55.49% vs 54.62%), and how it runs tonight in llama.cpp or MLX.
